# 质量判据：什么是瑕疵，以及怎么给自己打分

> 这份文件回答两个问题：**什么算没做完**、**凭什么说自己做完了**。
> 判据必须机器可判，否则它只是形容词。执行入口：`npm run selfgrade`，输出 `out/verification/selfgrade.json`。

## 一、瑕疵的七种形态

| 编号 | 形态 | 机器怎么认 |
|---|---|---|
| D1 | **承诺未实现** | `core/ channels/ adapters/ scripts/` 出现 `TODO` / `TBD` / `FIXME` / 「稍后实现」/「待补」；或`SKILL.md` 写了参数而 CLI 不认 |
| D2 | **实现无判据** | 新增模块没有对应 `.test.mjs`；测试文件里 `assert.` 计数为 0；出现恒真断言 `assert.ok(true)`；机械门扫描计数为 0 却报 PASS |
| D3 | **等级夸大** | 占位图被写进回执的「真实出图」；`estimated` 被当成实测；L1 写成「已验证」 |
| D4 | **降级单点死** | 缺 key / 断网 / 无参考图 / 无建模环境任一情形下链路非零退出，或静默出假数据 |
| D5 | **文档-代码不一致** | `SKILL.md` / `README.md` / `traceability.md` 描述的行为与实跑不符 |
| D6 | **不可复现** | 干净安装后跑不通；依赖手工步骤；写死绝对临时路径 |
| D7 | **静默失效** | 通道「已配置」但判别 0 次真调用；台账里全是回退而回执写「降级：无」；接口在绑定时被吃掉却全程无报错 |

**判定原则**：六条任一命中即不合格交付，不看整体观感。宁可交一份「明确写着自己缺什么」的产物，也不交一份「看起来都绿」的产物——后者只是把缺陷挪到了评委发现它的那一刻。

D7 是七条里最阴的一条：它不报错、不降级、不退出非零，产出看起来齐全，只是**结论全部来自模板而不是模型**。机器认法很直接——拿台账的 `by_source` 与回执的 `degradations` / `evidence_levels` 对账，两边不一致即命中。`tests/chain/stages.test.mjs` 里有正反两个用例守着这条。

## 二、七项自评分表

每项 0–100，**不是加权平均制**：任一项不到 100 就不交付，只修那一项，重跑，直到七项全 100。

| # | 维度 | 满分条件 | 判据来源 |
|---|---|---|---|
| 1 | 功能完整度 | 六段流程全部可达，必需文件齐全，零占位承诺 | 静态扫描 + 文件存在性 |
| 2 | 判据强度 | 全量测试 0 失败；机械门 0 FAIL 且 ≥7 条 PASS；无空扫、无恒真断言 | `node --test` + `check-decouple` 真实退出码 |
| 3 | LLM 判别有效性 | 每个判别点同时具备**接受路径**与**拒绝路径**，且回退值过自身 schema | 用桩通道实际跑两遍（ok / invalid），断言 `source` 分别为 `llm` / `fallback` |
| 4 | 降级完备 | 五类缺失场景全部 exit 0 且带标注 | 真实执行：无 key、无参考图目录、无建模环境、无通道、零 key 全链路 |
| 5 | 可复现性 | 锁文件、依赖、四条命令、链路口令齐全 | 静态检查 + 已安装依赖 |
| 6 | 文档一致性 | SKILL 写到的参数 CLI 全认；三份文档无占位承诺 | 交叉比对参数表与 CLI |
| 7 | 成本纪律 | 有真实连通性证据；单价未查证时写 `null` + 原因；只记 token 不编金额 | `out/verification/llm-probe.json` + 回执字段 |

## 三、为什么要「拒绝路径」而不是只测通过

一个只会走通的系统，无法回答「模型胡说时你怎么办」。判别层最危险的失败不是报错，而是**返回一个形状正确、语义错误的对象**然后被下游照单全收。所以每个判别点都必须能被自己的 `check()` 否掉，且否掉之后下游拿到的是确定性回退——这条由 `G3-JUDGE` 门和 `tests/judge/points.test.mjs` 同时守。

## 四、自评不等于证明

自评是**内部一致性检查**，不是外部有效性证明。它能证明「说到的都做了、降级都能走」，不能证明「做出来的东西在真实平台上可用」。后者只能由 `handoff.md` 的人工提交（G14）与平台回读给出。所以：

- 自评七项全 100 ⇒ 可以交付**工程**；
- 平台侧提交与商品一致性未验 ⇒ **不得**对外称「可直接上架」。
