## 怎么读这张表

- **进口额大 + 中国份额高**：货已经在那里，竞争是价格与款式，不是市场教育。
- **进口额大 + 中国份额低**：要么有本地供给，要么有关税/合规门槛，值得先查门槛。
- **单价高**：能吃中高价位，但要注意当地购买力（见 `docs/市场底数.md`）。
- **单价低**：只能做量，毛利率会被物流吃掉，必须验证运费（见定价明细）。
