> 一句话：**把「AI 说它判断了」变成「能回放、能证伪、能算钱」的商品交付链路**——

## 一、三条命令看完全部

```bash

npm run chain -- --category 女装 --region RU --candidates 1 \
  --mock-llm --mock-images --run-id check-local                     # 零成本跑通全链路
```

## 四、诚实边界（评审可以直接拿这五条问）

1. **未提交平台**：`title.txt` 因平台标题模板 `unverified` 而不生成（给的是标 `candidate` 的稿子），`handoff.md` 写明原因；没有平台回读。
2. **展陈渲染≠商品三维**：几何复用建模技能的 `zoomcare-pillbox` 展位，商品本体不在场景内；`design.json` 材质色是否被渲染消费未做像素级验证。
3. **人群只能停在 hypothesis**：没有成交回流（0 单），`observed/validated` 由 schema 枚举挡住，模型写不出来。
4. **买家画像工具未验**：Ozon Customer portrait 需 Premium 且需 ≥1 单，未订阅。
5. **单价不折算**：图像模型单价官方页未取到数字，回执只记 token，不编金额。

## 五、评委最可能问的三件事

| 问 | 答（指向可核的东西） |
|---|---|
| 「模型胡说时你怎么办？」 | 每个判别点都能被自己的 `check()` 否掉 → 走确定性回退；回退值必须过同一份 schema（`G3-JUDGE`）。用例：`tests/judge/points.test.mjs` 的拒绝路径。 |
| 「凭什么说结论可信？」 | 不靠自评说可信：降级与证据等级都从台账 `by_source` 反算，全回退只能写 L1。用例：`tests/chain/stages.test.mjs` 正反两例。 |
| 「这套东西能迁移吗？」 | 法域是配置不是代码（`regions/*/profile.json`，9 个通过 schema）；换市场只改配置。用例：`scripts/add-region.mjs`。 |

## 六、目录分工

```
core/        判别、评分、出包、定价等纯逻辑（可单测）
channels/    三类外部通道：llm / imagegen / storage / source（可注入、可降级）
scripts/     CLI 与链路：chain / selfgrade / gates / chain-evidence / lookbook
schemas/     上品输入、事实、平台等契约（改这里不改代码）
regions/     法域配置（RU 完整，SA/AE/SEA 骨架）
data/        事实与人群假设（personas.json 每条必须带 falsifier）
tests/       361 项，含 51 个测试文件
docs/        质量判据（七种瑕疵 + 七项自评）、契约与追踪矩阵
out/         验证产物与证据（不参与运行）
```

## 七、不做什么（写死，避免范围蔓延）

- 不做 AI 自动改价、不代办平台提交、不绕过 WAF/验证码；
- 不在没有数据的地方硬造指标；估算必须标 `estimated` + 依据；
- 不把可预测事件（大促、换季）算进「应变」战绩。
