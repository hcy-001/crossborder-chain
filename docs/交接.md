# 交接说明（2026-10-31）

> 接这份文件的人（或 AI）应该能在 10 分钟内跑起来、知道哪里不能动、以及下一步该做什么。

## 一、这是什么

**跨境电商全链路 Skill**：给「品类 + 目标法域 + 候选数」，产出上架材料（母版图、平台投影、尺码映射、文案任务单、交付说明、可复核台账）。

**不是**全自动上架机器人：不调上架接口、不保存商户凭证、不自动提交、不自动花钱。

## 二、三条命令上手

**先跑这一条**，它就是「一个方向进去」的全部：

```bash
npm run chain:dir -- --direction "女士针织开衫" --region RU
# ① 方向验证 → ② 选品决策 → ③ 反查货源 → ④ 出包，最后列出 ⑤ 上架缺口
# clone 后想直接看产出：加 --intake data/intake/demo-ru.json（每项标注 measured/estimated/demo）
```

```bash
npm ci                 # 依赖只有 ajv + sharp
npm test               # 407 项，零网络零 key
npm run check:decouple # 7 道机械门（改完 core/ 或 data/specs/ 必须单独跑，test 不含它）
npm run quickstart     # 内置样例跑通全链路，5 秒，产出 handoff.md + onepager.html

npm run region:data    # 9 法域宏观底数（世界银行，免 key）
npm run region:calendar # 假日 + 月均气温（决定卖什么厚度、何时上新）
npm run platform:readiness # 平台就绪矩阵：谁能出包、缺什么
npm run research:render    # 渲染「要看多少东西」清单
npm run fx:refresh         # 10 个结算币种的汇率（缺一个该法域就没价）

npm run market:scan -- --direction "..." --region RU   # 只跑 ①（HS 映射 + 进口规模 + 款级信号）
npm run select:candidates -- --direction "..." --region RU   # 只跑 ②
npm run quotes:1688 -- --keyword "针织开衫"      # 只跑 ③ 的报价抓取（需 922 上已登录的 1688）
npm run source:lookup -- --direction "..." --region RU   # ③ 出采购规格书
```

`quickstart` 结束会打印成品包实际路径。**注意**：重复跑时目录变成 `package/<sku>__<时间片>/`（不覆盖旧产物），以回执 `package_dir` 为准。

## 四、不能随便改的契约

1. **定价口径**：平台费按**售价**抽，用分母法 `P = 固定成本 / (1 − 佣金率 − 税率 − 支付费率 − 目标毛利率)`。改成"成本加成"会让售价低估 26%（见 `docs/adr/0001-定价口径.md`）。
2. **回执结构**：`runs/<run_id>/chain.receipt.json` 的字段被测试与下游消费；改名要同步改 `schemas/receipt.schema.json` 与测试。
3. **core 层不得出现平台名 / 地区码 / locale**：机械门 `G1-CORE` 会拦（`npm run check:decouple`）。
4. **无网/无 key 必须能跑**：所有外部通道都有桩降级；新增通道必须同时给 fallback，否则 `npm test` 会红。
5. **数字类事实（费率/税率/时限）不得写死**：要么来自 `data/specs` 的 fact（带 status），要么来自用户答复。

## 七、踩过的坑（别重复）

1. **覆盖写会被某些安全策略计成"删除"**：所以目录存在时换新目录，不要试图"先清空再写"（`rm -rf` 直接被拦）。
2. **复制目录时 `ignore_patterns("package")` 会误伤 `core/package/`**：只排除顶层产物目录。
3. **`runs/latest-doctor.json` 是文件不是目录**：遍历时 `is_dir()` 判断。
4. **core 层写平台名/`ru-RU`/`RU` 会被门禁拦**：这些字面量只能在 `scripts/` 与 `data/`。
5. **问卷问了不用最伤人**：`cost`/`weight_g`/`size_chart_rows` 都曾"填了不生效"，现在都是"问卷优先、工单兜底"。
6. **复制别人 skill 的 `.env` 进仓库**会触发 `G1-PATH`（absolute home path）且带密钥，别做。
7. **"填了"不等于"能过"**：`attributes.csv` 里每个值都非空，但字典型字段填中文照样被打回。覆盖率报表必须搭配值形态检查一起看。
8. **别信中国卖家站的结构化 JSON**：尺码表那套 `country/category/measurements` 字段与官方构造函数对不上，是编的。官方要什么，去 `global-help.ozon.com` 看原文。
9. **官方站在高频抓取后会返回空正文**（SPA 空壳，`__rr=1` 重定向）。抓到的原文要立刻落盘到 `out/verification/`，否则结论无法复现。

## 八、下一步建议（按性价比）

1. **补 Ozon 只读凭证**（L3-1）：一次能解三件事——`Тип` 字典、跨品类规则、标题字段实际行为。
2. **后台粘一份 `#13164` JSON**（L3-2）：尺码表这条线从此闭环，不再"待换"。
3. **跑第二个真实品类**（L3-3）：把"样本=1"变成"样本=2"，这是商业侧最硬的一条。
4. **写权限**（L3-4）放在最后：没有只读侧的规则核实，写权限只会把错误更快地提交出去。
