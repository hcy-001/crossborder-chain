## 逐项：从哪拿

### 自己定（9 项）

#### `platform` — 这批货要上哪个平台？（填平台名；两个都上的话两个都写）

- **性质**：阻断出包（不可留空）
- **从哪拿**：自己定。不确定就先跑 `npm run platform:readiness`，看目标法域哪几家能出包
- **抄什么**：平台名；两个都上就都写（如 ozon, wildberries）
- **查不到怎么办**：写 unknown → 尺码与标题规则都定不了，只能出包不能上架
- **这条路径的证据等级**：`L1` — 本地跑通，但没真的从后台/报价单抄到值
- **为什么问**：两个平台的尺码结构、标题规则、图片比例、变体规则都不同：同一件货不能复用一套字段。

#### `seller_account_status` — 你在平台上的账号到哪一步了？（开户未开店 / 已开店 / 还没有账号）

- **性质**：阻断出包（可写 unknown）
- **从哪拿**：自己知道。没有账号就先看 `npm run platform:readiness` 里该平台的「需凭证」说明
- **抄什么**：三选一：已开店 / 开户未开店 / 还没有账号
- **查不到怎么办**：写 unknown 按「未开店」处理：字段名一律标未核，不得声称可上架
- **这条路径的证据等级**：`L1` — 本地跑通，但没真的从后台/报价单抄到值
- **为什么问**：这条决定后面几件事能不能做：能不能自己去后台核字段名、能不能拿到本类目的佣金率、能不能提交。没店的人不缺口径，缺的是店。

#### `return_policy` — 退货怎么处理？（谁承担运费、有没有本地退货地址、几天无理由）

- **性质**：阻断出包（可写 unknown）
- **从哪拿**：平台规则页（退货时限、谁承担运费）＋你自己的承受力。没有本地退货地址就必须写清，否则买家退货成本会吃掉利润
- **抄什么**：一句可执行的话：几天无理由、退货运费谁出、有无本地退货地址
- **查不到怎么办**：写 unknown → 履约段出不来，不能提交
- **这条路径的证据等级**：`L0` — 按信息性质推断，未亲自走一遍
- **为什么问**：服装退货率高；退货成本与退货地址是上架前置条件，平台侧通常是必填项。

#### `credentials_path` — 平台凭证放在哪个文件？（.env 的绝对路径；不把密钥贴进对话）

- **性质**：需确认（可写 unknown）
- **从哪拿**：自己保管，**放仓库外**。本项目实测可用形态：`~/.workbuddy/skills/<skill>/.env`（含 Client-Id / Api-Key 两行）
- **抄什么**：绝对路径即可，**不要把 key 粘进对话或仓库**
- **查不到怎么办**：不给 → 只出待核包，不出可提交包
- **这条路径的证据等级**：`L2` — 本项目实测过这条路径（真的走通了，或真的被挡住）
- **为什么问**：有了凭证才能把"猜的规则"换成"平台自己说的"：类目树、必填属性、字典取值、佣金、能否写入。没有凭证时本工具只出待核包，不出可提交包。凭证一律放在仓库外，且不复制进项目。

#### `publishing_mode` — 出包之后怎么办：人工提交，还是让工具提交？

- **性质**：需确认（不可留空）
- **从哪拿**：自己定，默认人工提交。要工具直接提交，得同时具备：读写 key + 明确类目 + 能回滚（下架接口权限）
- **抄什么**：人工提交 / 工具生成草稿 / 工具直接提交
- **查不到怎么办**：不答按「人工提交」处理（最安全）
- **这条路径的证据等级**：`L1` — 本地跑通，但没真的从后台/报价单抄到值
- **为什么问**：提交是有副作用的一步：一旦上架就会有曝光与订单。默认停在"材料齐备"这一步，把取舍留给卖家。

#### `image_host_kind` — 商品图放在哪里？（平台只收公网 URL；公用图床已实测全部不可用）

- **性质**：需确认（可写 unknown）
- **从哪拿**：自有对象存储 / 自有 CDN / 店铺自带图床。**公用图床本项目实测四家全不可用**（一家停上传、三家超时或被拦），必须自己的
- **抄什么**：类型名；顺带确认图片可匿名读（不带签名）
- **查不到怎么办**：没有图床 → 能提交但商品建不出来（`is_created=false`），这是静默失败，比报错更费时间
- **这条路径的证据等级**：`L2` — 本项目实测过这条路径（真的走通了，或真的被挡住）
- **为什么问**：各平台的图片字段只接受公网可访问 URL，不接受本地文件、也不接受 data URI。本次实测：四家公用图床服务全部不可用（一家已停上传，三家超时或被拦）——这条路走不通。所以图床必须由卖家提供，工具只负责把图放到该地址下并按平台规格命名。

#### `image_host_base_url` — 图床的 URL 前缀是什么？（拼上文件名就能访问的那种）

- **性质**：需确认（可写 unknown）
- **从哪拿**：在你的对象存储控制台看「访问域名/CDN 域名」，把目录前缀带上；实测方式是拼一张已存在的图，用浏览器打开能出图（HTTP 200 + Content-Type: image/*）
- **抄什么**：到目录为止的前缀，不含文件名（形如 https://<域名>/img/misc/）
- **查不到怎么办**：不填 → 不做图片预检，问题会推迟到平台审核阶段才暴露
- **这条路径的证据等级**：`L2` — 本项目实测过这条路径（真的走通了，或真的被挡住）
- **为什么问**：提交时要把每张图写成完整 URL 并回读校验可访问性（HTTP 200 + Content-Type 为 image/*）。前缀不对会得到 404，而平台的报错只会说「图片无效」，不会告诉你是路径错了。

#### `fulfillment` — 发货方式是哪一种？（FBS 自己发 / FBO 发到平台仓 / RFBS）

- **性质**：需确认（可写 unknown）
- **从哪拿**：平台支持的履约模式（自发货 / 平台仓 / 海外仓）＋你有没有仓。俄罗斯常见 FBS（自发货）与 FBO（平台仓）
- **抄什么**：模式名；同时说明发货地与时效
- **查不到怎么办**：写 unknown → 库存与时效无法确定
- **这条路径的证据等级**：`L0` — 按信息性质推断，未亲自走一遍
- **为什么问**：决定仓储费、时效承诺、退货地址落在哪，也决定运费能否按包干估算。

#### `spreadsheet_or_api` — 最后是人工在后台填，还是用表格/ERP 批量传？

- **性质**：可默认（可写 unknown）
- **从哪拿**：自己定。人工填最稳；走 API/ERP 会先被接口校验拒一次，字段名与类型要求更严
- **抄什么**：人工填 / Excel 模板 / ERP
- **查不到怎么办**：不答按人工提交
- **这条路径的证据等级**：`L1` — 本地跑通，但没真的从后台/报价单抄到值
- **为什么问**：本链路不代提交；走 API/ERP 的字段校验标准不同，会先被接口拒一次。

### 工具可算（6 项）

#### `vat_rate` — 税费按多少算？（写百分数或小数；由谁承担写清楚）

- **性质**：阻断出包（可写 unknown）
- **从哪拿**：看你是谁：中国跨境卖家在 Ozon 是 **0%**（出口零税率，平台报错原文 `vat_not_zero_banned_in_country` 明确要求填 0）；本地主体按法域标准税率，`regions/<CC>/profile.json` 的 `tax_reference` 有参考值与出处
- **抄什么**：小数（0 / 0.05 / 0.15 / 0.22）；主体类型一并写清，否则这项必错
- **查不到怎么办**：写 unknown → 定价不含税，可能低估成本
- **这条路径的证据等级**：`L2` — 本项目实测过这条路径（真的走通了，或真的被挡住）
- **为什么问**：税负随政策变动，必须以官方口径为准；申报价与售价必须分开记。

#### `credentials_scope` — 这把 key 的权限范围是什么？（决定是"只做预检"还是"直接发布"）

- **性质**：需确认（可写 unknown）
- **从哪拿**：不确定就跑 `npm run probe:account -- --platform <p> --env <路径>`：用「参数必然非法但不落地数据」的请求探，三态 granted / denied / unknown
- **抄什么**：只读 / 读写 / 让工具探
- **查不到怎么办**：探不出来就是 unknown —— 那不等于「没权限」，只表示探测路径打不通
- **这条路径的证据等级**：`L2` — 本项目实测过这条路径（真的走通了，或真的被挡住）
- **为什么问**：只读 key 与读写 key 能做的事差一个数量级。选"不确定"时由 scripts/probe-account.mjs 用"参数必然非法但不落地数据"的请求探出来，不靠人猜。

#### `gender` — 目标人群性别是哪一个？（用目标市场语言写平台的取值，不是写中文）

- **性质**：需确认（可写 unknown）
- **从哪拿**：方向词里就有（「女士针织开衫」→ 女）；`chain:dir` 会自动填
- **抄什么**：女 / 男 / 中性
- **查不到怎么办**：不答按方向词判断
- **这条路径的证据等级**：`L1` — 本地跑通，但没真的从后台/报价单抄到值
- **为什么问**：性别同为平台必填属性，且是字典型取值：写成中文「女」会被字典校验拒掉，必须写平台字典里的那一项。

#### `target_language` — 标题和描述要不要当地人校一遍？（还是机翻后自己看一遍就行）

- **性质**：需确认（可写 unknown）
- **从哪拿**：目标法域决定（RU→俄语）；`chain:dir` 自动填。注意：俄语必须用西里尔字母，禁止用拉丁字母拼俄语
- **抄什么**：语言名
- **查不到怎么办**：不答按法域默认
- **这条路径的证据等级**：`L1` — 本地跑通，但没真的从后台/报价单抄到值
- **为什么问**：机翻在服装类目读起来像坏句子，直接影响转化与审核。

#### `model_usage` — 商品图能用模特吗？（含 AI 模特；品牌方有没有限制）

- **性质**：需确认（可写 unknown）
- **从哪拿**：平台图片规则（已核官方原文）：成人服装用**模特站立实拍**；童装内衣/泳装/连体衣必须**平铺且不用模特**；任何情况**不得出现人台**
- **抄什么**：你要用哪种：模特实拍 / 平铺 / 无模特场景
- **查不到怎么办**：不答按「成人装模特站立实拍」处理
- **这条路径的证据等级**：`L2` — 本项目实测过这条路径（真的走通了，或真的被挡住）
- **为什么问**：白底主图不能有人；场景图是否用模特涉及品牌调性与平台规则。

#### `currency_and_payout` — 回款是什么币种、多久结一次？

- **性质**：可默认（可写 unknown）
- **从哪拿**：平台合同币种。Ozon 可查：`POST /v1/seller/info` 返回 `currency`（本项目实测为 CNY，因为主体是中国公司）；其他平台看后台结算设置
- **抄什么**：币种码（CNY / RUB / AED …）
- **查不到怎么办**：不答按法域默认，但**合同币种与定价币种不一致会被平台拒**
- **这条路径的证据等级**：`L2` — 本项目实测过这条路径（真的走通了，或真的被挡住）
- **为什么问**：回款币种与周期决定汇率风险敞口，长周期回款等于隐性汇损。

### 自己实测（3 项）

#### `size_chart_rows` — 尺码表的具体数字是多少？（一个码号一行，写「码号: 胸围, 衣长」；没有就写 unknown）

- **性质**：阻断出包（可写 unknown）
- **从哪拿**：两条路：① 后台尺码表模板自带的档位；② 自己量样衣（胸围/衣长/肩宽，平铺量）。**不要用「42=XS」这类换算表**——那是行业惯例，不是平台官方标准，本项目已明确不写死
- **抄什么**：一行一个码：「码号: 胸围, 衣长」；至少覆盖你要卖的 4 个码
- **查不到怎么办**：写 unknown → 平台侧填不了尺码表，包能出但不能提交
- **这条路径的证据等级**：`L1` — 本地跑通，但没真的从后台/报价单抄到值
- **为什么问**：尺码图与平台属性都要用真实数字；只有码号没有数值，等于给了半张表。

#### `weight_g` — 单件**带包装**多重？（克）

- **性质**：阻断出包（可写 unknown）
- **从哪拿**：厨房秤称样衣（单件、含基本包装）；或让供应商实测后写在报价单上。别用同行均值——克重不足是压价最常见手段
- **抄什么**：整数克。同一款多码不同重就取最大码
- **查不到怎么办**：写 unknown → 出不了定价（运费按重量算）
- **这条路径的证据等级**：`L1` — 本地跑通，但没真的从后台/报价单抄到值
- **为什么问**：跨境运费按计费重（实重与体积重取大）算；只给净重会系统性低估运费。

#### `package_dimensions_cm` — 包装尺寸是多少？（长 × 宽 × 高，厘米；三个数字）

- **性质**：阻断出包（可写 unknown）
- **从哪拿**：按实际发货形态量：折叠装袋/装盒后，用卷尺量最长三边。**填小会被罚**（Wildberries 要约 13.3 条），填大会多付仓储与物流费
- **抄什么**：三个数字：长 × 宽 × 高（厘米），按长>宽>高
- **查不到怎么办**：写 unknown → 打包规格不确定，平台侧体积重算不出来
- **这条路径的证据等级**：`L1` — 本地跑通，但没真的从后台/报价单抄到值
- **为什么问**：轻的东西按体积重计费，只填实重会少算运费；体积重除数按渠道口径不同（本链路默认 6000，可改）。

### 卖家后台（4 项）

#### `platform_size_field` — 后台商品页里，尺码那一格叫什么名字？（照抄后台显示的名字；没看过就写 unknown）

- **性质**：阻断出包（可写 unknown）
- **从哪拿**：平台卖家后台 → 新建/编辑服装类商品 → 尺码那一格显示的字段名。公开接口拿不到（本项目实测被 WAF 挡、开发者文档有反爬），只有后台可见
- **抄什么**：照抄后台显示的原文（如 Российский размер / techSize），不要翻译
- **查不到怎么办**：写 unknown → 尺码映射照做但标「字段待核」，不声称可直接上架
- **这条路径的证据等级**：`L1` — 本地跑通，但没真的从后台/报价单抄到值
- **为什么问**：字段名只在后台可见（公开接口被 WAF 挡、开发者文档有反爬）。开店的人上架时天天见这个名字，所以开局就问，不留到事后补。

#### `size_system` — 尺码用哪套？有没有本地码和国内码/国际码的对照表？

- **性质**：阻断出包（可写 unknown）
- **从哪拿**：平台该类目的尺码表模板（后台商品页里的「尺码表 / размерная сетка」）；目标市场用哪套码就填哪套
- **抄什么**：码制名 + 范围（如「俄码 42–52」）；有国际码对照就一并写
- **查不到怎么办**：写 unknown → 尺码表只能出结构不能出数字
- **这条路径的证据等级**：`L0` — 按信息性质推断，未亲自走一遍
- **为什么问**：俄码与国际码不是同一套数轴；平台只认本地码，国际码仅作对照。服装审核常见的拒因之一就是尺码标注不合本地标准。

#### `platform_commission_rate` — 这个类目的平台佣金是多少？（写百分数或小数都行）

- **性质**：阻断出包（可写 unknown）
- **从哪拿**：卖家后台的费率/佣金页（按类目分行）。**接口拿不到**：本项目实测 `/v1/product/commission` 返回 404，只有商品建出来后能从商品信息里读到实际值
- **抄什么**：该品类的百分比；注意有些平台按含税价计、有些按不含税价计，一并记下
- **查不到怎么办**：写 unknown → 定价会按未扣佣金处理，毛利偏高；交付里标「佣金未核」
- **这条路径的证据等级**：`L1` — 本地跑通，但没真的从后台/报价单抄到值
- **为什么问**：佣金按类目阶梯，差几个百分点就是利润差；口径不同会算错净利。

#### `payment_fee_rate` — 回款/支付手续费多少？（写百分数或小数）

- **性质**：阻断出包（可写 unknown）
- **从哪拿**：结算单上的「支付手续费 / 提现费」行；或平台费率页的结算条款。问财务/代运营要最近一期的实际扣费比例
- **抄什么**：小数（如 0.02）
- **查不到怎么办**：写 unknown → 按 0 处理，毛利略偏高
- **这条路径的证据等级**：`L0` — 按信息性质推断，未亲自走一遍
- **为什么问**：这项常被忽略，但按流水扣，回款周期越长影响越大。

### 供应商（3 项）

#### `cost` — 采购价多少？（人民币，不含运费）

- **性质**：阻断出包（可写 unknown）
- **从哪拿**：① 1688 搜索列表报价：`npm run quotes:1688 -- --keyword "<词>"`（本项目实测 55 条：P25 29.7 / 中位 39.0 / P75 58.5 CNY）；② 供应商正式报价单，问清含税否、是否含包装
- **抄什么**：单件人民币价。**标明取的是哪一档**（最低价/中位/某家报价）
- **查不到怎么办**：写 unknown → 只出包不出价（定价段直接跳过）
- **这条路径的证据等级**：`L2` — 本项目实测过这条路径（真的走通了，或真的被挡住）
- **为什么问**：成本是定价的起点；含税与不含税差一个进项税，直接影响毛利。

#### `color` — 商品主色是什么？（用目标市场语言写，只填一个主色）

- **性质**：需确认（可写 unknown）
- **从哪拿**：候选已给建议值（`npm run select:candidates` 的输出）；最终看你能拿到的色卡
- **抄什么**：主色名；多色就列全，注意颜色×尺码会乘出 SKU 数
- **查不到怎么办**：不答按候选建议值
- **这条路径的证据等级**：`L1` — 本地跑通，但没真的从后台/报价单抄到值
- **为什么问**：颜色是平台必填属性，而选品工单里经常没有这一栏。不能从商品图推：同一张图在不同显示器上不是一个颜色，猜出来的值会同时错颜色和错字典项。

#### `material_composition` — 面料成分和比例是多少？（有检测报告就提一句）

- **性质**：阻断出包（可写 unknown）
- **从哪拿**：供应商的成分检测报告或水洗标照片。**不接受口头承诺**——虚标含毛量是主要退货原因；候选的材质档给了目标值（腈纶 70%+ / 羊毛 30–50% / 羊毛 70%+）
- **抄什么**：按百分比写全（如「腈纶 70%、羊毛 30%」）
- **查不到怎么办**：写 unknown → 属性填不进去，且平台上架后有虚标风险
- **这条路径的证据等级**：`L1` — 本地跑通，但没真的从后台/报价单抄到值
- **为什么问**：服装类目必填属性；成分写错直接推高退货率，还涉及虚假描述。

### 货代财务（2 项）

#### `international_shipping_fee_cny` — 国际段运费一件多少？（人民币；按重量分档的话，填这件的档位）

- **性质**：阻断出包（可写 unknown）
- **从哪拿**：货代报价单。问法固定三句：这件 400g 到 <目的国> 多少钱一票/每公斤？挂号还是平邮？时效多少天？
- **抄什么**：单件人民币运费；按重量分档就取这件所在档位
- **查不到怎么办**：写 unknown → 毛利算不出，不能判断能不能做
- **这条路径的证据等级**：`L0` — 按信息性质推断，未亲自走一遍
- **为什么问**：运费是跨境最大的一项变动成本，且随重量跳档；估错会吃掉全部毛利。

#### `insurance_fee_cny` — 有没有投保？一件保费多少？（没有就写 0）

- **性质**：需确认（可写 unknown）
- **从哪拿**：货代或保险单：按货值比例，或每票固定几元。小包多数不含，问货代「丢件怎么赔」就有答案
- **抄什么**：单件人民币；没有就填 0（明确是 0，不是未知）
- **查不到怎么办**：写 0 并注明「未投保」，不要把 0 当默认值蒙
- **这条路径的证据等级**：`L0` — 按信息性质推断，未亲自走一遍
- **为什么问**：保险影响理赔上限；默认「没保」是最常见的隐性损失。

### 资质服务商（2 项）

#### `certs` — 这个品类要的认证有哪些？现在有哪几份？（EAC / GOST / 质检报告）

- **性质**：阻断出包（可写 unknown）
- **从哪拿**：① 平台该类目的合规要求页；② 检测机构/服务商（俄罗斯服装是 ЕАС 声明；**诚信标签 Честный знак 是另一件事**，且 EAC 证书主体、标签申请主体、报关主体必须一致）
- **抄什么**：现有哪几份证、编号、发证主体、有效期；没有就写「无」并注明缺哪份
- **查不到怎么办**：写 unknown → handoff 会标 BLOCKED，包能出但不能上架
- **这条路径的证据等级**：`L1` — 本地跑通，但没真的从后台/报价单抄到值
- **为什么问**：缺认证会被平台审核拒，而拒因不会告诉你补什么。

#### `brand_authorization` — 这是你自己的牌子、白牌，还是别人的牌子？（别人的话有授权书吗）

- **性质**：阻断出包（可写 unknown）
- **从哪拿**：自有品牌→商标注册证；代理→授权书；白牌→平台字典里的「无品牌」值（Ozon 实测有效值 `126745801:Нет бренда`）
- **抄什么**：三选一 + 依据：自有品牌（证号）/ 代理（授权书）/ 白牌（用无品牌）
- **查不到怎么办**：写 unknown → 品牌属性填不进去，提交会被拒
- **这条路径的证据等级**：`L2` — 本项目实测过这条路径（真的走通了，或真的被挡住）
- **为什么问**：没授权就上品牌款是侵权下架的高频原因，平台处罚重。

## 等级说明

| 等级 | 含义 |
|---|---|
| `L2` | 本项目实测过这条路径（真的走通了，或真的被挡住） |
| `L1` | 本地跑通，但没真的从后台/报价单抄到值 |
| `L0` | 按信息性质推断，未亲自走一遍 |

等级说的是**这条获取路径**被验证到什么程度，不是这条信息本身多重要。`L0` 不代表值不可信，只代表「我还没亲自走一遍这条路」。
