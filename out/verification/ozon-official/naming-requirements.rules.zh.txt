===== 自动 / 手动 =====

您可以用以下方式来命名商品标题：

自动
对于服装和鞋类类目，名称会根据商品的必填特征自动生成，格式为类型 + 品牌 + 服装和鞋类系列。
对于其他所有类目，名称会根据商品的必填特征自动生成，格式为品牌 + 类型 + 型号 + 该商品类目的重要特征。

手动
您可以自行指定将显示在网站上的名称，但名称必须符合要求。
请按以下格式填写名称：品牌 + 类型 + 型号 + 该商品类目的重要特征。

===== 自动生成标题的类别 =====

系统会自动为指定的类别生成商品名称，而不管名称字段如何填写。

汽车用品，医药保健，家用电器，电子游戏，服饰用品和配饰，居家生活，印刷书籍，美容与健康，
家具，音乐，鞋子，服装，维修与施工，运动与休闲，珠宝饰品，电子产品。

===== 商品名称应该是什么样子的 =====

| 对名称的要求 | 说明 |
| 应指出商品相关类型 | 比如：娃娃，柜子，智能手机，垃圾桶（"书籍"类目除外） |
| 应以大写字母开头 | 比如：台座，水杯 |
| 应由允许的字符组成 | 可以使用：俄语和英语字母；数字；符号：. , : ; ( ) - / & "；感叹号和问号，如果没有它们名称将不正确（比如，如果感叹号是书籍名称的一部分） |
| 不能包含禁用符号 | 不能使用下列符号：商标 ™；版权标识 ©；注册商标 ®；[ ] , = , \ , « » 。系统会自动将不符合要求的符号替换为空格 |
| 最大长度 | 一个词——27个字符。整个名称——200个字符。 |
| 在长名称中必须要包含所有的标点符号 | 请用以下符号来分割名称：. , "" / |
| 名称应是语法通顺的句子 | 审核人员将不会批准名称为"娃娃女孩玩具儿童塑料"的商品 |
| 不能包含两个以上单根词 | 型号列举除外 |
| 不含广告等不必要的信息 | 名称包含下列内容将不批准："促销"、"大甩卖"、"折扣"、"只有今天"；商品价格；"最佳商品""独特商品""惊艳商品"等；"类似""仿制品""copy""1:1""原版""original""正品"等字眼 |
| 不能包含音译词语或大写字母 | 例外：允许缩写（GOST）与生产商名称（SEGA）。若名称中有大写字母拼成的词语（如"KUKLA[娃娃]，ADAPTER[充电器]"），审核将不批准 |
| 不能包含隐藏的格式字符 | 用专门服务或手动编辑检查 |
| 不能包含搜索同义词 | 例："镜子壁式镜子浴室镜子走廊镜子化妆镜子大镜子"不合适 |
| 不能包含其它来源的链接或引用 | 比如："请在小册子中查看更多信息" |
| 不能包含不间断的空格 | & n b s p ; |
| 不能包含 HTML 标记 | < p >, < a >, < b > |

===== 审核商品名称时常见的错误（官方列举） =====

| 错误 | 正确示例 | 错误示例 |
| 商品名称过长 | Ablueday Головоломка "Кубик катамино", 54 детали | （一长串堆砌词） |
| 名称中用词不一致 | Кукольный театр "Красная шапочка", 4 персонажа | Кукла маппет мальчик девочка играть с перчатка… |
| 名称为拉丁语 | MAC Mineralize Skinfinish Natural Минеральная пудра, Light, 10 гр | MAC Mineralize Skinfinish Natural, Light |
| 没有标点符号的长名称 | Рюкзак школьный 3 в 1: … | （150+ 字符无逗号） |
| 名称中有很多特殊符号 | KLAPP A CLASSIC … Крем для лица, 30 мл | Крем от морщин для: увлажнения, эластичности… |
| 很多重复 | LACALUT Зубная щетка Kids 4+, мягкая щетина, желтая | Мягкая зубная щетка / Щетка для детей от 4 лет / … |
| 词语过长 | TRIBE Сумка для ноутбука, 16 дюймов, чёрная | ЭлегантнаяСумкаTRIBE… |
| 名称中有很多用大写字母写成的词语 | Hygiene Жидкое средство для стирки, аромат Sunrise Kiss, 600 мл | ГЕЛЬ ДЛЯ СТИРКИ ПАРФЮМИРОВАННЫЙ HYGIENE… |
| 名称中包含过多商品类型列举和/或同义词 | Herbalife Протеиновый батончик со вкусом лимона, 35 гр, 12 шт | 12 протеиновых батончиков Herbalife… |
| 名称中含有不允许的符号，如表情符号或汉字 | Lipton Чай листовой черный, 150 г | Чай 叶茶 «Lipton™», 250克 |
