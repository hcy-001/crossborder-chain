To help you avoid Non-Saleable Item Storage Fees and manage your non-saleable inventory efficiently, noon provides the Non-Saleable Recommended RTV Report. This report details non-saleable items stored in noon fulfillment centers that are eligible for retrieval or removal. This guide explains how to access the report and provides a detailed breakdown of the columns included. How to access this report? Accessing this report is a very easy and simple procedure. All you have to do is follow the simple steps given below. 1- Click on the Navigation menu , then select Fulfilled by noon and choose Reports. 2- Click on Generate Report . 3- Under Report Name , select a category and choose Returns . From the Returns Reports tab, select Non-saleable Recommended RTV Report. Choose a Close Date and then click on Generate Report to complete the process. ​ Explanation of the columns in the sheet: Download header Description Example value run_date The date till which the data is updated.
