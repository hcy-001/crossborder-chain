How to setup your automated return preference? Managing your inventory efficiently and avoiding unnecessary storage fees is critical. Noon’s Automated Returns feature allows you to automate the retrieval of saleable and non-saleable items stored in fulfillment centers. This guide explains how to access and configure this feature, as well as additional actions you can take on the Automated Returns Dashboard. Note: 1. Your stock retrieval will be based on the preferences you have saved by the 25th of the month. 2. Any expired inventory stored in the noon warehouse for more than 30 days will be disposed of by noon and will not be liable for any payments or disputes. 3. Your automated returns for grocery warehouse will be processed every Monday. 4. Any expired inventory store for 2 consecutive Mondays in the noon warehouse will be disposed of, and noon will not be liable for any payments or disputes. How to access the Automated Returns in Seller Lab? - Go to Fulfilled by Noon , then select My Returns . - Click on Automated Returns or click on Manage Automated Returns in the top left corner of the screen. You will be redirected to a page where you can configure your preferences for automated returns for Sort, Non-Sort, and Bulky warehouses. How to set up your preference for Automated Returns For UAE and EGY Select your Return Preferences based on the warehouse type. For KSA The preference setup includes a city-level filter . You can select preferences for each city, depending on the warehouse type. Automating Returns for Different Warehouse Types You can set up the automated preference for each warehouse type as per your requirement. There are two type of Return Preference for each warehouse. Warehouse Type Return Preference Sort Warehouse 1. Delivery 2. Dispose Non-Sort Warehouse 1. Pickup 2. Dispose Bulky Warehouse 1. Pickup 2. Dispose Return Preference (Delivery & Pickup) The process to setup your delivery and pick up return preference is similar and follows the same flow. Lets understand this in a step-by-step process. - Once you select the preference as delivery or pickup you will need to select the delivery address. Click on Choose Delivery Address . - In the pop-up that appears you will find an option to Create an address if you don't have a saved address. If you have a saved location you can select it to complete setting your preference . - To add a new address you will need to select the pin location on the map and confirm it. Then provide the detailed address details and select the address type. Then click on Add User . - If you have an existing user, you can select it to proceed. If not you can create a new one by click on Create New Contact. Once it is approved you can use the user to complete the address. Add User In case you have to add a new use you can follow these simple steps You click on the Create New Contact. Provide the name and verify the email ID and phone number with the OTP. Once it is verified click on Create. - Once you have selected the user you can review the address and contact details and if everything is good you can click on Review & Confirm. - Once the address is added you will see a notification. - Once the address is added to the list, select the address and then click on Save to complete the process. - Once the delivery preference is added you will see the details under the relevant warehouse. Return Preference (Dispose) You can also select to dispose option for your return preference. If you select dispose as the option, noon will liquidate the stock and you wont be able to claim reimbursement for that stock. Lets understand this process in detail. - Click on Dispose option, in the return preference. Then click on Verify OTP . - In the next step, enter your phone number. The click on Send OTP. You will get an OTP on Whatsapp. Enter the OTP then click on Confirm . - You will get a confirmation once the number is verified. - You will notice the dispose address and the return preference is successfully set for the respective warehouse. Once the return preference is set for all the type of warehouse, you will notice a completeness seek on the top left corner of the screen. Other action that can be taken You also have an option to take some additional action on the automated return page. Lets discuss these options. - Click on the action button in the return preference. In the pop-up you will notice two options. - Click on View change log option. - A pop-up appears on the screen that shows all the changes in the preference log that were made. - You can also click on Disable Preference to disable the preference for that warehouse type. Note: You cannot disable preference for the expired items. - You will see a pop-up to confirm your selection. Click on Disable Preference . That’s it! Got more questions?
