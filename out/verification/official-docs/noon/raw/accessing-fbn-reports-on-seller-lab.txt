The FBN Reports in Seller Lab provide a centralized and streamlined solution for tracking and analyzing your Fulfilled by Noon (FBN) inventory. These reports cover everything from stock levels to returns and inbound processes, enabling better inventory management and decision-making. Steps to Access FBN Reports Navigate to Seller Lab : Go to the main Seller Lab page and click on the navigation menu in the top left corner. Access Fulfilled by Noon Reports : Click on Noon.com → Fulfilled by Noon . Select FBN Reports . In the top right, click on Generate Reports . Select Report Category and Report Type : Choose the report category and the specific report you wish to download. Generating the Report After selecting the desired report: Set report-specific filters (e.g., opening/closing date or close date). Click Generate to complete the report generation. You now have your FBN report ready to download and analyze. Available FBN Report and Descriptions FBN reports are divided into categories such as Inventory , Returns , and Inbound . Below is an overview of the key reports available: Report Category Report Name Filters Brief Description Inventory FBN Inventory Detail Report Close Date This report provides a snapshot of your inventory at the end of the close date. Inventory FBN Inventory Ledger Report - Summary View Opening Date Closing Date This report provides you with the opening and closing stock within a date range selected along with an aggregated value of all transactions that occurred in between. Inventory FBN Inventory Ledger Report - Detailed View Opening Date Closing Date This report provides you with details of every inventory transaction that occurred in between a given date range. Inventory Stock Movement Report Opening Date Closing Date This report provides you with details of every inventory transaction that occurred in between a given date range. Inventory Stock Reconciliation Report Year Month This report provides you with the opening and closing stock for a selected month and an aggregated value of all transactions that occurred in between. Returns Saleable Recommended RTV Report Close Date This report provides an overview of the saleable items that are recommended for returning to avoid long-term storage fees. Returns Non-saleable Recommended RTV Report Close Date This report provides an overview of the non-saleable items that are recommended for returning to avoid long-term storage fees. Returns RTV Report - Requests Opening date Closing date This report provides all the details of the RTV requests created within the specified period. Returns RTV Report - Shipments Opening date Closing date This report gives an overview of all the shipments created, which requests they belong to as well as any disputes raised on the shipment/items inside.
