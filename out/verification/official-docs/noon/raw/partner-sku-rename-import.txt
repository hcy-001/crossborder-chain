This feature allows you to rename your existing partner_sku without needing to delete it, in case it was named incorrectly or requires updating. Follow this guide for a smooth, successful import process, covering the import columns and step-by-step instructions. Import Template: Required Fields here is a brief on all columns / data you would need to include in your import file, id_partner Required 2604 Your unique partner id that identifies your account and your products, you could find it in any export or in the import template Psku_Code Required a51578b667d96d04e0fb34d This code is generated as soon as you create your own partner_sku. It is a standardized alphanumeric code that will not change. When making subsequent imports you can either use this value or your partner_sku or both. rename_partner_sku Required Atta2604 Your new partner_sku name that you are importing as the new one. Best practices and tips for Import Download the Template : Start by downloading the template, which will automatically include your id_partner. Partner_SKU Formatting : Use a simple format for your partner_sku that consists of letters and numbers without spaces Avoid special characters like these: / - + If your partner_sku is all numbers avoid using multiple zeros at the start or the end. File Format : Save your import file as either .xlsx or .csv . Excel files should be saved with Unicode Text encoding, as the Product Catalog does not accept .xls files. Ensure each partner_sku is listed in a single row. Please note that the psku_code will not change after you rename the partner_sku.
