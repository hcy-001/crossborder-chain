Packing the orders to create the shipment for handover is a very crucial part of the Directship process. Depending on your warehouse size, you might have a small warehouse with only one or two packers, or you might have a large warehouse with a team of packers. The warehouse setting will now allow you to select your preferred fulfillment mode. In this article, we will discuss each of these fulfillment mode as given below. Single Packer mode Multi Packer mode How to Set up your Fulfillment mode? In order to set up your fulfillment mode, follow these simple steps. - Click on Fulfilled by Partner and then click on Warehouse . - Click on Configure Warehouse. - Click on the Fulfillment Method option. - In the next step, you get an option to choose to select the Single packer mode or the Multi- packer mode. You can make your selection and then click on Save Changes. Note: You can make this selection only if you are a project owner or a project admin with the permission role of Update. What is Single Packer Fulfillment Mode? The Single Packer mode is more suitable for small warehouse where we have only one of two packer. The orders can be packed easily and efficiently without any errors. You don't have to create any sessions in this flow and can manually select the orders easily. Under the Single Packer mode the order flow remains same for mobile and web version as mentioned below. - Login to the application and go the warehouse from where you are fulfilling the order - Select the order you want to fulfill. - Pack the order by creating a shipment to fulfill the order. You can refer to this article to know more about how to fulfill the order using the mobile application, and refer to this article to understand the order processing from the web. What is Multi-packer Fulfillment Mode? The Multi Packer Mode is more suitable for sellers who have a large warehouse receiving a lot of orders, which will be processed by a team of packers. To ensure that the orders are not mixed up and assigned properly to individual packers, each packer can create a separate session. Note: The default mode for new warehouses is Single Packer. You can switch from Single to Multi packer whenever you like. To use this mode on mobile, packers must start sessions, or to use it on the web, you can fulfill only unassigned orders To switch from Multi to Single Packer, you must first complete all active sessions. You can also force close the session only if you are a project owner or a project admin with the permission role of Update. If you opted in for the multi-packer mode, you will be able to find the following actions available for you. - When you click on Pending orders, you will notice a blue button labeled Start Packing Session . Click on this button and enter the number of orders you can fulfill in that session. Once you fill in the number, click on Confirm . The unassigned orders with the least/ nearest estimated shipping date are automatically assigned to you. - Once you start processing the orders, you will see how many orders you have fulfilled in comparison to the number of order you created the session with. Note: - If the session is closed without finishing, → session remains active. - Inactive sessions expire after 2 hours of inactivity (based on last action time taken in that session - not based on just opening the session ). - While the session is active, "Start Packing Session" becomes "Continue Packing Session" with the orders left count. - If the session is about to expire, you will get the remaining time in the session. - Once you complete all the orders assigned to you, you see the same in the top-left corner of the screen. You can click on Finish Session to close the session. A confirmation pops-up showing the session is closed. - If the order is not assigned to you, or if the order is assigned to someone else, you will see the following errors. Note: If the order is not added to your active session. You cannot take action on that order. If the order is assigned to another user. You cannot take action on that order. - While processing the order, if you get a new order assigned to you, you will notice a pop-up showing the number of orders assigned. You can select the order you want to process and click on Add orders . The order you don't select, since they are unassigned, remains unassigned. A confirmation pops up showing the assigned order is processed. - You can also click on the action button at the top of your assigned order session to view more options. This shows two actions that you can take. If you select the Pending Item view option, the application shows the item-wise view of the SKU. It shows how many orders we received for the SKU. - If you proceed to click on Quit Session , you just need to confirm your selection by clicking Yes, Quit Session. This will close the session for you. The unfinished order move back to the unassigned orders. - If you are in multi-packer mode and have the project owner or the project admin access with the permission role of update , you can click on More Actions and select Active sessions on mobile . - This will show you all the active sessions that have orders assigned to them. You can click on Force Close if you want to close any session. - In the Multi-packer mode, you can process the pending orders that are not yet assigned. You can click on create shipment in the pending orders to view the order details and check if the order is assigned or not. That’s it! Got more questions? Contact us at seller@noon.com
