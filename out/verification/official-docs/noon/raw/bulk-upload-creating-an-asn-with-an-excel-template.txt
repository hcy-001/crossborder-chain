Bulk Upload: Creating an ASN with an Excel Template | noon Seller Help Center noon Seller Help Center › Fulfilled by noon (FBN) › Bulk Upload: Creating an ASN with an Excel Template Bulk Upload: Creating an ASN with an Excel Template Seller Lab lets you create an Advance Shipment Notice (ASN) by uploading your SKUs and quantities using an Excel file, instead of adding them one by one in the UI. Bulk Upload is the fastest way to create an ASN when you're shipping a large number of SKUs. Quick overview Starting a Bulk Upload: Creating an ASN using Bulk Upload involves 2 main steps: 1. Download the ASN Template Download the blank Excel template and complete the required information for the Partner SKUs you want to include in your shipment. 2. Upload the ASN Upload the completed Excel file to Seller Lab. The file will be validated, and you can review and resolve any errors before creating the ASN. Tip: Follow the screenshots and instructions under each step in order to complete the Bulk Upload successfully. ▶ Steps to starting a Bulk Upload : Go to noon.com , From Fulfilled by noon click My ASN & Storage. Click Create ASN, You will be directed to the Select SKUs step. Select Upload an Excel , then Click Continue . ▶ (1) Downloading the ASN Template On the Upload SKUs from a spreadsheet page : click ‘ Download now ’ to get the ASN Excel template. 2. The downloaded Excel worksheet contains ( 4 ) sheets : Instructions : Guidance on completing and uploading the template. Data Definitions : Required formats and validation rules for each field. Recommendation List : Suggested SKUs and quantities based on low-stock items. This sheet may be empty if no low-stock items are identified. Template : The sheet you need to complete. Enter your SKU and quantity details starting from row 11 . Note: The downloaded template is always a blank workbook. You do not need to wait for an “eligible lines” file to generate, even if you have a large catalog and you can start entering the data right away. ▶ What's Inside the Template ? Each sheet in the workbook serves a different purpose. Here's what to expect from each one. 1. Instructions The Instructions sheet provides a quick, numbered walkthrough of how to complete and upload the ASN template. Use it as a reference if you are completing the template for the first time or need a refresher. 2. Data Definitions A reference table that explains each field in the worksheet, including where it is used, what it means, whether it is required, and any applicable rules or conditions. Use this sheet whenever you are unsure what to enter in a field or which format to use 3. Recommendation List A read-only list of SKUs and suggested quantities based on an analysis of low-stock items. Use it as a reference when deciding which SKUs and quantities to include in your shipment. You do not need to copy the recommendations into the Template sheet, and this list is not required to create an ASN. It may be empty if no low-stock items are identified. 4. Template The sheet you actually fill in and upload. Headers are in row 9 , and your Partner SKU rows start from row 10 . It includes 6 columns: Partner SKU : Your product's SKU identifier, as used in your own catalog. Quantity : How many units of that Partner SKU you're sending. Longest Side, Median Side, Shortest Side (cm), and Weight (kg) : Package dimensions, needed only for Partner SKUs that don't already have dimensions saved in the system. Note: Don't rename the sheets, reorder the columns, or edit the column headers in row 9 — the upload is matched to this exact layout. Important: Longest Side, Median Side, Shortest Side, and Weight are only required for Partner SKUs that don't already have dimensions stored in noon's system. If a Partner SKU already has dimensions on file, these fields are optional and any values you enter here will be ignored. Dimensions can only be updated through Seller Lab > Product dimensions. ▶ (2) Uploading Your Completed File Once your template is complete, drag and drop the file into the upload area, or click Browse to select it from your computer. Accepted formats: .xlsx or .xlsm Maximum file size: 10 MB Maximum number of Partner SKUs: 8,000 - Click Continue . Every row is validated before your ASN is created. Congratulations✅🚀! You have successfully created your ASN using Bulk Upload. ▶ What If there are Errors ? If any rows fail validation, you'll see a summary telling you how many rows need fixing, along with a description of the issue. Click Error file (.xlsx) to download a report showing every row and column with an issue, along with a clear description of what needs to be fixed. Some errors relate to the file itself, such as a missing Template sheet or no data rows, rather than to a specific row. These errors are listed separately. The error report contains one row for each Partner SKU and may include multiple error descriptions for the same row. Once all errors are resolved and your file passes validation: Click Re-upload Corrected File to upload the updated Excel file. Click Continue to move to Review ASN Creation . Important: When you re-upload, include the entire file , every Partner SKU row, not just the ones that had errors. Each upload replaces the previous file completely, so rows left out of the corrected file won't be included in your ASN. Note: Validation also checks for catalog-level issues, such as missing images or pricing, so you can resolve them here instead of discovering them later. ▶ How to Fix validation Errors ?
