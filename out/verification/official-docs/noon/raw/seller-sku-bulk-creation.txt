In this example we have defined the size for the product and its sizing standard Handling Import Errors Once an import is successfully ingested, SKUs with valid content and no errors will be created on the catalog page. However, if there are errors in the file or we weren't able to create a SKU for any reason, an error file will be generated. Process to check the error. 1- Check Status: - Go to Catalog > Imports > Content . - Then search for the NIS Create/Update import. - Review the Status column for an overview and download any error reports if generated. 2- Resolve Errors: - Move to the rightmost columns in the error report to view specific issues. After correcting errors, re-upload the file. You will be able to see the report for each upload. The status columns give you an overview of your report. Import processes - file was processed by the system. Report generated - error report has been generated and is available for you to download.
