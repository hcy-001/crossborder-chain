如何优化商品详情页

关于商品详情页屏蔽的常见问题

要创建商品详情页，请进入“商品与价格”板块 → “商品详情页”，然后点击“添加”。选择“单个商品”。
关于如何一次性创建多个商品详情页，请参阅单独的指南。
如何正确填写商品详情页
正确填写的商品详情页是良好销售的关键。为了让商品详情页获得高评分，在商品目录中获得更好的排名，并在搜索和筛选中对买家可见，请遵循以下建议。
重要提示！
某些商品类目有填写商品详情页字段的特殊规则。
这些针对特定类目的规则已汇总在“商品类目”文章中。请务必阅读，以便正确填写商品详情页，避免罚款和屏蔽。
如果您使用俄语界面，则需直接使用俄语填写文本。俄语译文应保证专业度。如果文本中存在大量错误或描述不清，买家将难以通过搜索找到您的商品，同时商品详情页的评级也会下降。
如果您不懂俄语并使用中文界面，则需用中文填写所有字段。保存商品详情页后，系统会自动将文本翻译成俄语。
商品名称
显示在商品详情页标题中的商品名称。最大长度为 60 个字符。
商品名称在商品目录中可能无法完整显示，建议在选择词序时考虑这一因素。
名称应简短准确地回答“商品详情页图片中展示的是什么？”这一问题。不要有多余内容，只保留核心信息。所有细节可以在商品属性和描述中添加。
避免：
同义词和词语重复
不描述商品或描述不准确的词语
多余细节，例如成分或使用方法
用逗号或斜杠列举多个名称
标注性别和年龄
品牌名称
标注季节
主观评价，如“最佳”、“超级”、“爆款”
全大写字母书写的词语
仅使用拉丁字母、不含西里尔字母的词语
特殊符号：/ * - + @ № % & $ ! = ( ) { } [ ]
电话号码、邮箱、链接、即时通讯账号
表情符号
不雅词汇

18+
如果您销售成人用品，请勾选“18+”选项。
此时您的商品详情页将被模糊处理。
“18+”标签对于成人用品及某些类型的内衣是必填项。更多详情请参阅指南“成人用品：商品详情页设计规则”和“如何设计内衣商品详情页”。
您可以在商品详情页创建页面的侧拉菜单中找到它们。点击右下角的问号图标即可打开。
类目
当您输入商品名称或添加商品图片后，系统会自动推荐最合适的类目——您只需选择即可。
如果尚未填写名称，您可以自行查找类目：浏览列表或使用搜索框搜索。
重要提示！
某些商品类目有填写商品详情页字段的特殊规则。
这些针对特定类目的规则已汇总在“商品类目”文章中。请务必阅读，以便正确填写商品详情页，避免罚款和屏蔽。
卖家商品编号
您自己为方便搜索商品详情页而设定的唯一商品标识符。可随时修改。允许任何字符，但不超过 72 个字符。
注意不要将商品编号与条形码混淆：
商品编号是您的内部工具，无需印在商品上，可以是任意内容，我们不做任何查验或审核
条形码是仓库验收时扫描的代码，用于识别商品，必须印在包装上
使用星号图标可以随机生成商品编号：
品牌
品牌是印在包装或商品上的厂牌或商标。请从建议列表中选择品牌。
品牌必须与商品类目相符——例如，如果您选择了“服装”类目，建议列表中只会出现服装品牌。
品牌字段中请勿填写您卖家公司的名称。品牌是指商品本身的商标。品牌名称不得以符号开头，也不得与商品类目名称相同。品牌名称中禁止使用斜杠（/）和重复词语。
如果不选择品牌，该字段将自动显示“无品牌”。
如果列表中找不到您的品牌，您可以添加它——点击“添加品牌”进入品牌账户并开始创建。
更多关于创建品牌的信息，请参阅指南“如何在 Wildberries 上添加品牌”。
颜色
当您开始输入颜色时，系统会推荐合适的颜色选项。您最多可选择 5 个值。
建议只选一个主色——最贴切的那个。买家筛选器中的颜色是按基础色分组的：例如有“绿色”，但没有“草绿色”或“浅绿色”。因此选择“绿色”就足够了。
如果商品只有一个但包含多种颜色（例如一包多色袜子或带有双色印花的手机壳），请在同一个商品编号的商品详情页中列出所有颜色。也可以为一个商品编号指定同一颜色的多个色调。
如果不同颜色代表不同的商品（例如同款不同色的 T 恤），请为每种颜色创建单独的变体和商品编号。
要创建同款商品的不同颜色变体，请使用左侧的“变体”选项。
HS 编码
用于确定商品类目、海关税费金额及贴标要求的分类编码。
在“HS 编码”字段中只能从下拉列表中选择值。请仔细选择代码，因为这会影响验收单中是否出现标记码，以及在创建供货时是否会出现多余的标记商品标记。
请务必根据最新规则核对您选择的 HS 编码是否正确。
描述
描述应简洁、真实、信息丰富，并与商品相符。
描述中的字符数取决于父级类目。当您指定商品类目后，该类目允许的最大字符数会显示在“描述”板块的右侧。
不同类目商品描述的最大字符数如下：
5000字符：健康、药品
4000字符：家居、保险
3000字符：汽车电子、轿车、家具、食品、运动营养与化妆品、智能家居与安全、窗帘及配件、珠宝饰品
1000字符：酒类产品、数字内容
2000字符：其他所有类目
如何填写商品详情页的描述
简要介绍商品的特点、优势和使用场景。
在单次创建商品详情页时，有一个便捷功能：您填写描述后，系统会根据文本自动提取属性。
描述中无需列举所有属性——属性有单独的字段。
填写的属性直接影响商品展示的频率和受众。
如果属性字段为空，商品详情页的排名会大幅下降，更难出现在搜索结果中。因此，凡是能单独填写的内容（如尺码、颜色、成分、材质等），都请在专门的属性字段中填写。
描述中不要包含：
网站搜索会自动收录您的文本内容，并据此形成搜索关键词。
任何域名：.ru、.net、.com、.io 等，以及商品编号（包括自己和其他卖家的）
特殊符号，例如：/ * - + @ № % & $ ! = ( ) { } [ ]
颜色和商品变体的列举——只保留与当前商品详情页具体商品相关的内容
与您的商品无关的品牌
不雅词汇
过多提及尺码
所有为搜索结果所需的词语都应添加到商品描述中，不加特殊符号，使用空格分隔。

如何生成描述
商品属性
点击“显示全部”可查看所有属性字段。属性字段可能因商品和类目而异。
填写属性直接影响商品详情页的排名。您填写的属性越多，我们就能越精准地将您的商品展示给目标买家。
 如何填写属性：通用规则
属性必须与商品完全一致。如果值相互矛盾，商品详情页将无法进入商品目录的正确板块——买家在按筛选器搜索时无法看到它。
例如，如果晚礼服的“用途”字段填写了“运动”，它仍然不会出现在运动服装板块。
最好填写所有重要属性——这有助于更精准地向目标受众展示商品。建议从系统自动建议的值中选择。
如果需要填写多个值（例如颜色或成分），请分别填写。不要在一个字段中用逗号隔开填写——系统无法识别，商品将无法进入筛选器。
例如，如果在“成分”字段中写了“棉”，商品详情页会进入筛选器。如果在同一字段中写了“棉纸木”，系统无法确定准确值，商品详情页将无法进入筛选器。

部分字段的填写建议
成分
成分是构成最终产品的部分或元素的集合。所有元素必须完整填写，不得使用缩写或简称。成分不能是商品本身。
例如，在洗发水的商品详情页中，“成分”字段不应填写“洗发水 100%”，而应详细列出洗发水的组成：“椰油硫酸钠；甘油；葡萄糖苷；氯化钠；丁二醇；尿素；谷氨酸；精氨酸；赖氨酸；甘氨酸；尿囊素；乳酸”。

尺码表
仅部分类目有，例如服装和鞋类。
中国尺码与俄罗斯尺码不同。目前商品详情页中无法上传自己的尺码表。因此我们强烈建议在商品图片中添加包含您尺码参数的表格。请勿在文本描述中填写尺码，这会对排名产生负面影响。
如何在商品详情页中填写尺码
选择尺码表，然后逐个添加每个尺码。
正确填写尺码——尺码有 GOST 规定的特定范围。建议使用标准尺码表。
同一商品的所有尺码必须唯一且属于同一尺码表。
不要在“尺码”字段中添加无关文字，例如“促销”、“便宜”、“购买”等。
如果商品只有一个通用尺码，不要在“俄罗斯尺码”字段中写“无”或划横线。请填写该商品对应的俄罗斯尺码范围。

更多关于尺码表的操作信息，请参阅指南。
条形码
这是特定商品变体（特定颜色和尺码）的标识符。条形码可印在商品本身或其独立包装上。
条形码在商品验收和发货时会被扫描。因此，务必确保：
条形码已印在商品或包装上
条形码与商品详情页中填写的内容完全一致
如果条形码不匹配或缺失，商品将无法被接收。
最大长度为 30 个字符。可包含英文字母、数字和符号 / * - + @ № % & $ ! = ( ) { } [ ]，禁止在条形码中使用西里尔字母。
可以自动生成条形码——点击“生成条形码”即可。
包装尺寸
正确填写商品含包装的尺寸和重量至关重要——物流和仓储费用将根据这些参数计算。建议向上取整。
请只填写整数。数值不能为零，且不得超过 700 厘米。
如果填写的尺寸偏大，仓储和物流费用可能更高。如果填写的尺寸小于实际尺寸，将根据卖家要约第 13.3 条处以罚款。
我们会将您在商品详情页中填写的尺寸与类目平均值进行对比。如果发现差异，会显示通知。这有助于您及时发现并修正可能的错误。
图片和视频
无图片的商品不会向买家展示。
一个商品详情页最多可上传 30 张图片和 1 个视频。要上传图片，请点击“选择”。
或者通过链接添加图片和视频：
点击“+ 图片和视频”可添加更多文件。要替换、删除或将某张图片设为主图，请点击右上角的三个点，然后选择所需操作。
您还可以使用内置的图片编辑器。点击“打开编辑器”。
更多关于图片编辑器的工具信息，请参阅单独文章。
图片要求：
格式：JPG、PNG、WEBP
分辨率：最小 700 × 933 像素
压缩质量：不低于 65%
文件大小：不超过 10 MB
禁止上传以下内容的图片：
图片中没有您的商品
包含价格、二维码或折扣信息
包含联系方式或指向外部网站的链接
包含主观评价，例如“爆款”、“最佳”、“销量领先”、“顶级”
承诺为评论提供奖励
显示已售数量，例如“已售 500 件”
包含行动号召，例如“给经理打电话”、“对比商品”、“立即购买”
展示暴力或煽动仇恨

视频要求：
格式：MOV 或 MP4
帧宽：720 至 1920 像素
帧高：720 至 1920 像素
时长：不超过 3 分钟
视频编码：H.264 或 MPEG-4
音频编码：AAC 或 MP3
帧率：25–30 帧/秒
文件大小：不超过 50 MB
数量：最多 1 个
您可以从设备上传文件或提供直接链接。视频托管网站链接（如 BiliBili）或整个文件夹链接不可用。
您还可以使用“视频封面”服务，根据商品详情页中的图片生成视频封面。更多关于该服务的信息，请参阅指南。
图片中需要对来自外国代理人的书籍产品进行标记。更多详情请参阅指南“书籍产品标记的特点”。
完成商品详情页创建
填写完所有必填字段后，点击“创建并完成”。
如果商品详情页没有错误，它将出现在“所有商品”选项卡中；如果有错误，则出现在“草稿”选项卡中。
如何优化商品详情页
页面顶部显示商品详情页的完整度评分。
系统按 10 分制对商品详情页进行评分——考虑图片的数量和质量、属性填写情况、是否有描述等参数。
评分越高，商品详情页在商品目录中越具吸引力，排名也会越高。
该评分为内部可见，仅卖家本人能看到。更多关于商品详情页完整度评分的信息。
右侧有“优化商品详情页”按钮——点击可查看提示：哪些内容可以添加或修改以提高评分。
使用优化商品详情页的服务。它们可以帮助您快速、简单地提升商品详情页质量：
图片编辑器——帮助制作拼图、替换背景、添加文字和装饰元素
图片标记——带有其他商品（如不同尺码、颜色）的标签
虚拟试衣照相馆——创建 AI 模特展示您的商品
富媒体内容——从图片和描述中创建美观、信息丰富的商品详情页
A/B 测试——测试图片，帮助找出最吸引用户的版本
更多功能请参阅帮助中心专门板块“如何改善商品详情页”。
